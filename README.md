# 전광판 구조물 계산기 — 확장 초안

`dist/index.html`을 브라우저에서 열면 설치 없이 사용할 수 있습니다. 로컬 미리보기는 `node preview.cjs`로 실행합니다.

- 단면 또는 깊이형 프레임, 기본 규격과 12개 부위별 개별 규격 설정
- 사각관 4종, 직사각관 4종, H형강 3종의 대표 규격과 단면 형태 예시
- 정면 폭 b·깊이 방향 폭 d 분리 및 부재 90도 회전
- 바깥 치수, 부재 폭, 단위중량, 보강재 개수, 제작 수량 입력
- 부재별 절단 길이·수량·중량, 정면 배치도, UTF-8 BOM CSV 출력
- 입력한 전광판·기타 중량은 대당 값으로 합산
- 깊이형은 모서리 깊이 연결재 4개와 좌우 측면 보강재 포함, 좌우 측면도 제공
- 원자재 길이·톱날 손실·양끝 정리 여유에 따른 참고 구매 본수, 절단 패턴, 잔재 산출
- 원자재 초과 부재의 연장 길이·조각 수·이음 개소 및 규격별 기본/추가/총 구매 본수
- 연장 조각에 같은 규격의 잔재 우선 활용. 맞댐 0mm 기본, 이음부별 겹침 여유 선택 입력
- JSON 설정 저장·불러오기. 파일 내용은 브라우저에서 처리하며 서버로 업로드하지 않음
- 자재와 절단 패턴을 함께 CSV로 출력. 소수 합계는 반올림 전에 계산

## 계산 규칙

W=가로, H=세로, b=정면 부재 폭, V=세로 보강재 개수, R=가로 보강재 열 수, N=제작 수량입니다. 치수 단위는 mm입니다.

| 부재 | 개별 절단 길이 | 대당 개수 |
| --- | --- | --- |
| 외곽 세로재 | H | 2 |
| 외곽 가로재 | W − 2b | 2 |
| 세로 보강재 | H − 2b | V |
| 분할 가로 보강재 | (W − 2b − Vb) ÷ (V + 1) | R × (V + 1) |

위 표는 모든 부위의 규격이 같을 때입니다. 개별 설정 시 외곽 좌·우 폭의 합으로 가로재 길이를, 상·하단 폭의 합으로 내부 세로재 길이를 계산합니다. 가로/세로 보강재의 폭도 각각 반영합니다. 측면은 해당 좌/우 외곽 세로재의 d, 측면 상단/하단 연결재의 b, 해당 측면 보강재의 b·d를 적용합니다.

총길이(m) = Σ(완성 길이 × 부재 수량) ÷ 1000. 부재 중량 = Σ((완성 총길이 + 이음부 겹침 총길이) × 해당 단위중량). 전체 중량 = 부재 중량 + 기타 중량 × N.

초기값 4,000 × 2,000mm, 부재 폭 50mm, 3.34kg/m, 세로 3개, 가로 1열, 단면 1대는 부재 11개 / 총길이 21.25m / 부재 중량 70.975kg입니다.

깊이형에서는 위 표의 수량을 2배로 하고, `전체 깊이 − 2d` 길이의 모서리 연결재 4개를 대당 추가합니다. d는 깊이 방향으로 차지하는 부재 단면의 폭입니다. 전광판·기타 중량은 면 수와 관계없이 대당 한 번 합산합니다.

한쪽 측면의 세로 보강재를 n개, 가로 보강재를 r열로 입력합니다. 좌우 측면 세로재는 `H − 2b` 길이로 `2n`개, 좌우 측면 가로재는 `(전체 깊이 − 2d − nd) ÷ (n + 1)` 길이로 `2r(n + 1)`개입니다. 모두 제작 수량을 곱합니다. 앞뒤 외곽 세로재와 상하 모서리 연결재는 측면에서 재집계하지 않습니다.

측면 세로재는 깊이 방향 폭 d, 측면 가로재는 높이 방향 폭 b를 적용합니다. 길이는 외곽 단면 치수 기준 맞댐 길이입니다. H형강 코핑·플랜지 간섭·접합판 같은 실제 접합 상세는 포함하지 않습니다.

## 원자재 절단 배치

같은 규격·같은 원자재 길이의 부재를 그룹으로 묶습니다. 90도 회전은 같은 원자재로 묶고, 직접 입력 규격은 종류·구분 이름·단면 치수·단위중량으로 구분합니다. 재질이나 두께가 다르면 구분 이름을 다르게 입력해야 합니다.

원자재 초과 부재는 사용 가능 길이 U=원자재 길이−양끝 정리 여유로 자동 분할합니다. 완성 길이 L, 이음부당 겹침 a일 때 이음 개수 j=ceil((L−U)/(U−a)), 절단 조각은 U 길이 j개와 L−j(U−a) 길이 1개입니다. L≤U이면 분할하지 않습니다. 맞댐 a=0이 기본이며, 겹침 길이는 중량과 구매량에 추가됩니다. 실제 이음 위치·방법이나 접합부 상세는 이 계산의 범위 밖입니다.

일반 부재와 긴 부재의 첫 조각을 긴 순서로 배치해 **기본 본수**를 계산합니다. 그 잔재에 같은 규격의 연장 조각을 우선 배치하고, 남은 연장 조각에 필요한 원자재를 **연장용 추가 본수**로 구분합니다. **총 구매 본수=기본+연장용 추가**이며 추가 본수를 다시 더하지 않습니다. 반복 가능한 패턴을 수량으로 묶어 대량 제작도 처리합니다. 참고 배치이며 최소 본수를 보장하지 않습니다.

한 본의 길이 = 절단 조각 길이 + 톱날 손실 + 양끝 정리 여유 + 잔재. 끝단 잔재가 톱날 폭보다 짧으면 실제 남은 길이만 손실로 처리하고, 정확히 맞는 마지막 부재는 추가 손실 없이 배치합니다. 초기값에서는 6,000mm 원자재 4본, 구매 부재 중량 80.16kg입니다.

예: 10,000×2,600×600mm, 깊이형 1대, 전체 50×50×2.3t(3.34kg/m), 정면 세로 3개·가로 1열, 측면 세로 0개·가로 1열, 6,000mm 원자재·톱날 3mm·양끝 정리 0mm·맞댐 0mm이면 상하 가로재 4개가 각각 6,000+3,900mm로 분할됩니다. 연장 조각은 총 15.6m, 기본 13본+연장용 추가 4본=총 17본입니다.

규격별 단위중량은 아래 공급사 자료의 참고값이며, 실제 발주 제품과 일치하는지 확인해야 합니다. 지주, 판재, 볼트, 용접량, 상하면 추가 보강재, 구조 안전성 검토는 자동 계산 범위 밖입니다. 모든 단위는 mm, m, kg입니다.

## 규격표 출처와 이전 파일 호환

- 사각관·직사각관: [DS GROUP 각관 규격표](https://dsnp.kr/steel.html)
- H 100 × 100 × 6 × 8: [현대제철 Products Guide PART 02, KS/JIS 90](https://www.hyundai-steel.com/kr/down/2017_ProductGuide_Part2.pdf)
- H 150 × 150 × 7 × 10: [동국제강 제품 가이드](https://www.dongkuk.com/upload/pdf/product_guide2.pdf)
- H 200 × 100 × 5.5 × 8: [하피스 형강 자료](https://www.hapis.co.kr/hapis/resources/upload_file/C101/2025/04/41cf68bb402746c589ad6e7db69918ae_0.pdf)

설정 파일 버전 4에 기본 규격, 부위별 규격·회전·원자재 길이·구분 이름, 측면 보강재, 이음부 겹침 여유를 저장합니다. 버전 2·3도 불러오며 부위별 규격은 기본값을 따르고 겹침은 0mm로 복원합니다. 버전 2는 기존 폭을 d로 복사하고 새 측면 보강재를 0으로 설정합니다. 기존 3.44kg/m 같은 사용자 입력은 자동 변경하지 않습니다. 현재 규격표와 다르면 직접 입력 규격으로 복원합니다.
