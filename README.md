# 전광판 구조물 계산기 — 확장 초안

`dist/index.html`을 브라우저에서 열면 설치 없이 사용할 수 있습니다. 로컬 미리보기는 `node preview.cjs`로 실행합니다.

- 단면 또는 앞·뒤 2면 사각 프레임, 모든 부재에 동일 정사각 각관 적용
- 바깥 치수, 부재 폭, 단위중량, 보강재 개수, 제작 수량 입력
- 부재별 절단 길이·수량·중량, 정면 배치도, UTF-8 BOM CSV 출력
- 입력한 전광판·기타 중량은 대당 값으로 합산
- 앞·뒤 프레임에서는 모서리 깊이 연결재 4개 포함, 측면 개념도 제공
- 원자재 길이·톱날 손실·양끝 정리 여유에 따른 참고 구매 본수, 절단 패턴, 잔재 산출
- JSON 설정 저장·불러오기. 파일 내용은 브라우저에서 처리하며 서버로 업로드하지 않음
- 자재와 절단 패턴을 함께 CSV로 출력. 소수 합계는 반올림 전에 계산

## 계산 규칙

W=가로, H=세로, b=정면 부재 폭, V=세로 보강재 개수, R=가로 보강재 열 수, N=제작 수량입니다. 치수 단위는 mm입니다.

| 부재 | 개별 절단 길이 | 대당 개수 |
| --- | --- | --- |
| 외곽 세로재 | H | 2 |
| 외곽 가로재 | W − 2b | 2 |
| 세로 보강재 | H − 2b | V |
| 분할 가로 보강재 | (W − 2b − Vb) ÷ (V + 1) | R × (V + 1) |

총길이(m) = Σ(개별 길이 × 대당 개수) × N ÷ 1000. 각관 중량 = 총길이 × 입력 단위중량. 전체 중량 = 각관 중량 + 기타 중량 × N.

초기값 4,000 × 2,000mm, 부재 폭 50mm, 3.44kg/m, 세로 3개, 가로 1열, 1대는 부재 11개 / 총길이 21.25m / 각관 중량 73.1kg입니다.

앞·뒤 구성에서는 위 표의 수량을 2배로 하고, `전체 깊이 − 2b` 길이의 연결재 4개를 대당 추가합니다. 전광판·기타 중량은 면 수와 관계없이 대당 한 번 합산합니다.

## 원자재 절단 배치

같은 규격의 모든 부재를 긴 순서로 원자재에 채우며, 같은 패턴을 반복 가능한 수량만큼 묶습니다. 참고 배치이며 최소 본수를 보장하지 않습니다. 개별 부재가 사용 가능한 원자재보다 길면 구매 결과를 표시하지 않고 해당 부재를 안내합니다. 자재 산출표는 계속 표시합니다.

한 본의 길이 = 완성 부재 길이 + 톱날 손실 + 양끝 정리 여유 + 잔재. 끝단 잔재가 톱날 폭보다 짧으면 실제 남은 길이만 손실로 처리하고, 정확히 맞는 마지막 부재는 추가 손실 없이 배치합니다. 초기값에서는 6,000mm 원자재 4본, 구매 각관 중량 82.56kg입니다.

규격별 단위중량은 검증된 납품 데이터가 아닌 수정 가능한 예시값입니다. 제작 시 공급업체의 실제 단위중량, 접합 여유, 장비와 절단 방식을 반영해야 합니다. 지주, 판재, 볼트, 용접량, 모서리 이외의 추가 깊이 보강재, 구조 안전성 검토는 자동 계산 범위 밖입니다. 모든 단위는 mm, m, kg입니다.
