# 전광판 구조물 · 기초 통합 계산기

**`전광판_구조물_기초_통합계산기.html`을 더블클릭하면 설치 없이 두 계산기를 함께 사용합니다.** 코드·화면·풍속지도를 포함한 HTML 한 파일만 복사하면 됩니다. `dist/index.html`도 통합 화면이며, 로컬 미리보기는 `node preview.cjs`로 실행합니다.

## 통합 화면 사용

1. **구조물 계산기**의 간편 입력에서 **크기 입력 → 규격·보강 → 결과 확인** 순서로 작성합니다. 크기·제작 수량·제품 중량을 입력하고 자재와 보강재 개수를 정한 뒤 대당 중량·구매 본수·입력 금액을 확인합니다.
2. **기초 적용값 확인**에서 기존 기초 값과 적용할 치수·대당 중량을 비교합니다. 제품·캐비닛, 지주·프레임, 부속 중량을 실제 설치 내역과 확인한 뒤 적용합니다. 미확인 항목은 전체 요약에 계속 표시됩니다. 깊이형은 전체 깊이도 전달하며, 단면형은 기초 화면의 전광판 깊이를 유지합니다.
3. **기초 계산기**에서 설치지역·높이·지반·기초 개수·배근 조건을 입력합니다. 구조물 제작 대수와 기초 개수는 별도 입력입니다. 기존 풍하중·지반값·기초 배치·단가는 가져오기로 변경하지 않습니다.
4. **현재 기초 배치 반복**으로 동일 배치의 설치 횟수를 입력합니다. 예를 들어 한 전광판을 기초 3개로 지지하는 배치를 5회 반복하면 전광판 5대·기초 15개입니다. 반복 횟수는 전체 요약과 통합 산출서에 반영하며, 기초별 하중을 임의로 나누지 않습니다. 개별 기초 화면·도면·출력은 배치 1회 기준입니다. **제작 수량 맞춤**은 다른 기초 항목의 설치 대수를 제외하고 현재 배치를 정수 횟수로 맞춥니다.
5. **전체 요약**에서 모든 기초 항목의 콘크리트·철근·앵커·설치 수량과 계산 상태를 확인합니다. 미검토 형식, 자동 후보 없음, 지반·풍하중 자료 미확인, 제작·설치 수량 차이를 표시합니다. **두께별 후보 비교**는 기존 예비 계산 범위에서 현재 두께 주변 최대 3개 조건의 치수·물량·입력 금액을 비교하며, 검색만으로 치수를 바꾸지 않습니다.
6. **현장 단가 확인**, 0원 항목의 **다른 공종 포함·무상 확인**, **중복 비용 확인**을 각각 표시합니다. 구조물 단가가 완료되고 기초 단가·중복 비용도 확인되면 입력 금액 합산을 표시합니다. 단가·금액 조건을 바꾸면 관련 확인을 다시 해야 합니다. 초기 단가는 예시입니다.
7. **통합 작업 저장**으로 양쪽 입력·기초 목록·단가·연동·중량 확인·반복 수량을 JSON에 저장합니다. **작업 메뉴 → 작업 불러오기**는 통합 JSON과 기존 구조물 V2~V5 및 기초 JSON을 지원합니다. 통합 파일은 두 계산기를 모두 검증한 후 적용하므로 잘못된 파일은 기존 작업을 바꾸지 않습니다.

작업명은 상단에서 공통으로 관리하며 양쪽 출력에 반영합니다. 입력은 브라우저에 자동 저장되고 마지막 숫자·이름 입력도 저장·종료 전에 확정합니다. 오류가 있으면 마지막 정상 저장본을 유지합니다. **작업 메뉴 → 새 통합 작업**은 기존 작업의 백업 JSON을 다운로드한 뒤 새 작업을 시작합니다. 중요한 작업은 다운로드된 파일도 보관하세요.

중량 전달은 설치된 완성품 기준입니다. `캐비닛 중량 ÷ 대수 ÷ 화면 면적`은 기초의 전광판 면적당 중량에, `(부재 + 판재·부속품) 중량 ÷ 대수`는 지주·프레임 중량에, 기타 장비 중량은 추가 고정중량에 적용합니다. 구매 원자재·잔재의 무게는 기초 하중에 포함하지 않습니다. 구조물 또는 전달받은 기초 값을 바꾸면 **다시 적용** 표시가 나타나며, 버튼으로 갱신합니다.

**전체 요약 → 통합 엑셀·CSV·인쇄/PDF**에서 공통 작업명, 전체 기초 항목, 반복을 적용한 물량, 부속 자재, 확인 상태와 구조물 산출서를 출력합니다. 그라우트 주문은 배치 1회에서 올림한 포수에 반복 횟수를 곱하며 배치 간 남은 재료 공유는 별도입니다. 각 계산기의 기존 출력과 기초 CAD DXF·SVG도 사용할 수 있습니다. 통합은 기존 계산식과 예비 검토 범위를 유지합니다.

## 빌드·검수

`node build-all.cjs`로 기초 단일 HTML(`전광판_기초_철근_계산기.html`)과 통합 단일 HTML을 함께 재생성합니다. 통합 화면 상단과 작업 메뉴에 `구조물 V5 · 기초 V7 · 빌드일`이 표시됩니다. 통합 빌드는 필수 스타일·스크립트 참조가 누락되면 실패합니다.

`node --test tests/*.test.cjs`로 계산, 저장, 입력 오류, 연동, 전체 물량, 단가 확인, 후보 비교와 브라우저 출력을 검증합니다. 브라우저 테스트는 Playwright와 Edge가 있는 환경에서 실행하며(다른 브라우저는 `TEST_BROWSER_CHANNEL=chromium`처럼 지정) 독립 브라우저 세션을 사용합니다. 실제 작업 브라우저의 저장 데이터는 변경하지 않습니다.

## 기초 물량 계산기 (2026-10-21)

**`전광판_기초_물량계산기.html`**: 기초 치수만 입력하면 터파기·버림·잡석·콘크리트 타설(주문량)·거푸집·되메우기·잔토 반출·철근 물량을 바로 보여 줍니다. 풍하중·지반·구조 검토 단계 없이 기초 계산기와 같은 물량 계산식을 씁니다. 목 1개 독립기초, 목 2개 복합기초, 목 없는 블록기초를 지원하며 같은 기초 개수를 곱한 전체 물량과 엑셀·CSV·인쇄를 제공합니다. 소스는 `dist/quantity/`, 빌드는 `node build-quantity.cjs`(또는 `build-all.cjs`)입니다.

## 지주·앵커 예비 검토 (2026-11-04)

기초 계산기 **상세 입력 → 기둥·베이스플레이트·앵커**에서 기둥 두께와 앵커 묻힘깊이를 입력하면 중앙 1주 독립기초의 강재 지주와 앵커를 계수하중으로 예비 검토합니다. 두께나 묻힘깊이가 0이면 검토하지 않으며, 통합 요약에는 `예시 조건 충족 · 확정 전`(지주·앵커 입력)으로 표시합니다. 계산은 `dist/foundation/steel.js`에 있습니다.

- **지주 단면:** 원형 강관(외경·두께), 각형 강관(가로·세로·두께), H형강(춤 H·플랜지 폭 B·웹 tw·플랜지 tf). H형강은 웹을 정면 풍향(전광판 면에 직각)으로 둡니다. 기둥 하단은 목 상단(베이스플레이트)이고, 길이는 화면 상단까지입니다.
- **지주 검토 (KDS 41 31 00 / AISC 360 방식):** 정면·측면 휨(조밀·비조밀 판 요소, H형강 횡비틀림 Lb=기둥 길이·Cb=1.0), 축력(K=2.0 캔틸레버), 휨·축력 조합식, 전단을 확인합니다. 세장 판 요소는 `적용 범위 밖`으로 미충족 처리합니다. 2차 효과와 압축 국부좌굴은 고려하지 않습니다. 상단 처짐은 사용 풍하중의 참고값이며 판정에 넣지 않습니다.
- **앵커 검토 (KDS 14 20 54 / ACI 318 17장 방식):** 강체 플레이트·볼트군 탄성분배로 최대 인장 볼트를 구하고, 들림이 불리한 `안정용 자중계수 × 상부 중량 + 풍하중계수 × 풍하중` 조합을 씁니다. 강재 인장·전단(그라우트 패드 0.8), 인장 그룹의 콘크리트 콘 파괴(목 단면 연단, 3면 이상 근접 시 hef 조정, 균열 콘크리트 φ=0.70), 뽑힘(머리·너트: 육각 맞변 1.5da 가정, 갈고리: eh=3da), 인장·전단 조합, 최소 간격 4da·연단거리 6da, 묻힘깊이 공간을 확인합니다.
- **판정:** 지주·앵커 미충족은 기초 판정을 미충족으로 만듭니다. 자동 치수 탐색은 기초 항목만으로 치수를 정하므로, 지주·앵커가 미충족이어도 기초 치수는 그대로 표시하고 맨 위 경고에 수정할 항목을 안내합니다.
- **베이스플레이트 두께 (AISC Design Guide 1 방식):** 사각 플레이트에서 두께를 입력하면 정면·측면 방향마다 압축 측 그라우트 지압(fp,max = 0.65×0.85fck√(A2/A1), 압축 합력 = 볼트 압축 측 반력 + 고정하중계수 × 상부 중량)과 인장 측 바깥 줄 앵커 인장(유효폭 = 줄의 볼트 수 × 2x, 플레이트 폭 이하)의 휨을 구해 필요 두께 √(4Mu/0.9Fy)와 비교합니다. 위험 단면은 기둥 면의 0.95d(각형·H형강 춤), 0.8bf(H형강 플랜지), 0.8D(원형 강관)입니다. 강종은 SS275·SM355이며 두께별 항복강도(SS275: 16mm 이하 275, 40mm 이하 265, 그 이상 245 MPa)를 적용합니다. 지압 길이가 플레이트 절반을 넘으면 미충족입니다. 원형 플레이트의 휨은 별도 검토입니다. 두께를 넣으면 부속 물량에 플레이트 중량(kg)이 추가됩니다.
- **별도 검토:** 기둥–플레이트 용접, 앵커 측면파열·전단 콘크리트 파괴·프라이아웃, 앵커 보강철근, 목 P–M, 복합·다주 기초의 지주 반력 분배.

좁은 목에 앵커를 두면 콘크리트 콘 파괴가 지배하는 경우가 많습니다. 목 주근을 앵커 보강철근으로 상세 설계하는 경우는 이 계산의 범위 밖이며, 구조 담당자가 확인해야 합니다.

### 플레이트·앵커 자동 산정

**플레이트·앵커 정하기 → 기둥 단면에 맞춰 자동 산정**을 고르면 기둥 단면·두께를 입력한 중앙 1주 독립기초에서 사각 플레이트 크기·두께와 앵커 개수·직경·연단거리·묻힘깊이를 정해 입력칸에 채우고 잠급니다. 앵커 정착 형태·강도, 플레이트 강종, 그라우트 두께는 입력값을 씁니다.

- 후보: M20·M24·M30·M36·M42 × 4·8·12개, 정사각 플레이트 50mm 단위, 묻힘깊이 250~1,500mm 50mm 단위, 표준 판 두께 10~100mm. 플레이트 끝~볼트 중심은 max(2da, 60mm), 볼트 중심~기둥 면은 1.5da 이상(너트·공구 여유)으로 둡니다.
- 선정: 모든 앵커 검토·플레이트 지압·두께를 통과하는 조합 중 플레이트와 앵커(묻힘깊이 + 플레이트 + 그라우트 + 3da 길이) 강재 중량이 가장 작은 것을 고르고, 같으면 볼트 수가 적은 쪽을 고릅니다.
- 목 확대: 입력한 목 치수에서 통과 조합이 없으면 목 가로·세로를 100mm씩 키워 처음 통과하는 목을 씁니다. 기초 치수·목 철근·물량은 키운 목으로 계산하고 맨 위 경고에 표시합니다. 입력칸의 목 치수는 다음 탐색의 최솟값으로 그대로 둡니다. 상한은 기초 자동 탐색이면 `탐색 상한 − 2(정착길이 + 피복)`, 수동 치수면 푸팅 가로·세로(최대 3,000mm)입니다.
- 실패: 기둥 두께가 없거나 상한까지 조합이 없으면 입력값으로 검토하고 이유를 경고에 표시합니다. 복합·다주 기초에서는 선택할 수 없습니다.
- 통합 화면의 두께별 후보 비교는 현재 결과에서 정한 플레이트·앵커·목을 고정해 비교합니다.

### 구조물 탭의 지주 → 기초 기둥 검토

구조물 계산기 **규격·보강 → 지주·받침·추가 부재**(상세 입력은 **추가 부재**)에서 지주 행의 **기초 지주**를 체크하면, **기초 적용값 확인**으로 적용할 때 그 자재의 단면·두께가 기초의 강재 기둥 입력으로 전달됩니다. 지주 중량은 이전과 같이 지주·프레임 중량에 포함됩니다.

- 대응: 원형 강관 → 원형 강관(외경·두께), 사각관·직사각관 → 각형 강관, H형강 → H형강(웹 두께·플랜지 두께). 정면 풍하중은 구조물의 깊이 방향으로 작용하므로 정면 폭 b가 기둥 가로, 깊이 방향 폭 d가 기둥 세로가 됩니다. 90° 회전하면 서로 바뀝니다.
- 전달하지 않는 경우(기초 값 유지, 확인 창에 이유 표시): 90° 회전한 H형강(웹이 전광판 면과 나란함), 단면 종류가 직접 입력인 자재, 두께가 없는 자재, 기초 입력 범위(50mm 미만 등)를 벗어나는 단면.
- 확인 창의 `지주 단면` 행에 현재 기초 값과 적용 후 값을 보여 줍니다. 구조물 지주의 대당 개수가 기초 배치의 대당 지주 수와 다르거나, 지주 길이가 `화면 하단 높이 − 목 노출고`보다 짧으면 `적용 전 확인` 항목으로 표시합니다. 지주 강재 검토는 중앙 1주 독립기초에서만 계산합니다.
- 여러 부재를 기초 지주로 표시하려면 같은 자재·방향이어야 합니다. 개수는 합산하고 길이는 가장 긴 값을 씁니다.
- 구조물 규격표에 **원형 강관** 6종(Ø114.3×4.5t ~ Ø318.5×6.9t)을 추가했습니다. 단위중량은 KS D 3566 식 `W = 0.02466 t (D − t)` kg/m입니다. 더 큰 각형 강관·H형강은 자재의 단면 종류를 고른 뒤 직접 입력하세요.

## 구조물 간편·상세 입력

## 계산 규칙

W=가로, H=세로, b=정면 부재 폭, V=세로 보강재 개수, R=가로 보강재 열 수, N=제작 수량입니다. 치수 단위는 mm입니다.

| 부재 | 개별 절단 길이 | 대당 개수 |
| --- | --- | --- |
| 외곽 세로재 | H | 2 |
| 외곽 가로재 | W − 2b | 2 |
| 세로 보강재 | H − 2b | V |
| 분할 가로 보강재 | (W − 2b − Vb) ÷ (V + 1) | R × (V + 1) |

위 표는 모든 부위의 규격이 같을 때입니다. 개별 설정 시 외곽 좌·우 폭의 합으로 가로재 길이를, 상·하단 폭의 합으로 내부 세로재 길이를 계산합니다. 가로/세로 보강재의 폭도 각각 반영합니다. 측면은 해당 좌/우 외곽 세로재의 d, 측면 상단/하단 연결재의 b, 해당 측면 보강재의 b·d를 적용합니다.

총길이(m) = Σ(완성 길이 × 부재 수량) ÷ 1000. 부재 중량 = Σ((완성 총길이 + 이음부 겹침 총길이) × 해당 단위중량). 전체 중량 = 부재 중량 + 기타 중량 × N.

초기값 4,000 × 2,000mm, 부재 폭 50mm, 3.34kg/m, 세로 3개, 가로 1열, 단면 1대는 부재 11개 / 총길이 21.25m / 부재 중량 70.975kg입니다.

깊이형에서는 위 표의 수량을 2배로 하고, `전체 깊이 − 2d` 길이의 모서리 연결재 4개를 대당 추가합니다. d는 깊이 방향으로 차지하는 부재 단면의 폭입니다. 전광판·기타 중량은 면 수와 관계없이 대당 한 번 합산합니다.

현재 V5 계산기에서 자동 추가가 켜져 있으면 앞뒤 세로 보강재의 일치하는 중심선마다 상·하단 연결재 2개/대도 추가합니다. 동일 규격·방향으로 앞뒤를 연동한 경우 길이는 `전체 깊이 − 2d`이고 총개수는 `세로 보강재 개수 × 2 × 제작 수량`입니다. 기본 4,000×2,000×600mm 깊이형, 세로 3개·가로 1열·측면 가로 1열·3.34kg/m은 500mm 연결재 6개를 포함해 부재 34개, 총길이 48.5m, 프레임 중량 161.99kg/대입니다.

한쪽 측면의 세로 보강재를 n개, 가로 보강재를 r열로 입력합니다. 좌우 측면 세로재는 `H − 2b` 길이로 `2n`개, 좌우 측면 가로재는 `(전체 깊이 − 2d − nd) ÷ (n + 1)` 길이로 `2r(n + 1)`개입니다. 모두 제작 수량을 곱합니다. 앞뒤 외곽 세로재와 상하 모서리 연결재는 측면에서 재집계하지 않습니다.

측면 세로재는 깊이 방향 폭 d, 측면 가로재는 높이 방향 폭 b를 적용합니다. 길이는 외곽 단면 치수 기준 맞댐 길이입니다. H형강 코핑·플랜지 간섭·접합판 같은 실제 접합 상세는 포함하지 않습니다.

## 원자재 절단 배치

같은 규격·같은 원자재 길이의 부재를 그룹으로 묶습니다. 90도 회전은 같은 원자재로 묶고, 직접 입력 규격은 종류·구분 이름·단면 치수·단위중량으로 구분합니다. 재질이나 두께가 다르면 구분 이름을 다르게 입력해야 합니다.

원자재 초과 부재는 사용 가능 길이 U=원자재 길이−양끝 정리 여유로 자동 분할합니다. 완성 길이 L, 이음부당 겹침 a일 때 이음 개수 j=ceil((L−U)/(U−a)), 절단 조각은 U 길이 j개와 L−j(U−a) 길이 1개입니다. L≤U이면 분할하지 않습니다. 맞댐 a=0이 기본이며, 겹침 길이는 중량과 구매량에 추가됩니다. 실제 이음 위치·방법이나 접합부 상세는 이 계산의 범위 밖입니다.

일반 부재와 긴 부재의 첫 조각을 긴 순서로 배치해 **기본 본수**를 계산합니다. 그 잔재에 같은 규격의 연장 조각을 우선 배치하고, 남은 연장 조각에 필요한 원자재를 **연장용 추가 본수**로 구분합니다. **총 구매 본수=기본+연장용 추가**이며 추가 본수를 다시 더하지 않습니다. 반복 가능한 패턴을 수량으로 묶어 대량 제작도 처리합니다. 참고 배치이며 최소 본수를 보장하지 않습니다.

한 본의 길이 = 절단 조각 길이 + 톱날 손실 + 양끝 정리 여유 + 잔재. 끝단 잔재가 톱날 폭보다 짧으면 실제 남은 길이만 손실로 처리하고, 정확히 맞는 마지막 부재는 추가 손실 없이 배치합니다. 초기값에서는 6,000mm 원자재 4본, 구매 부재 중량 80.16kg입니다.

예: 10,000×2,600×600mm, 깊이형 1대, 전체 50×50×2.3t(3.34kg/m), 정면 세로 3개·가로 1열, 측면 세로 0개·가로 1열, 6,000mm 원자재·톱날 3mm·양끝 정리 0mm·맞댐 0mm이면 상하 가로재 4개가 각각 6,000+3,900mm로 분할됩니다. 연장 조각은 총 15.6m, 기본 13본+연장용 추가 4본=총 17본입니다.

규격별 단위중량은 아래 공급사 자료의 참고값이며, 실제 발주 제품과 일치하는지 확인해야 합니다. 지주, 판재, 볼트, 용접량, 상하면 추가 보강재, 구조 안전성 검토는 자동 계산 범위 밖입니다. 모든 단위는 mm, m, kg입니다.
